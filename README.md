
# CivicFix AI 🏙️

**From Citizen Reports to Verified Resolution**

CivicFix AI is an Agentic AI-powered civic complaint management system developed for the **Agentic AI × SDG Hackathon**. It helps streamline urban problem reporting by intelligently classifying complaints, detecting potential duplicates, assigning responsible departments, tracking deadlines, and escalating unresolved issues.

### ✨ Key Features
- 📝 **Citizen Complaint Reporting** — Report potholes, garbage, broken streetlights, water leakage, and other civic issues.
- 🤖 **Smart Complaint Classification** — Automatically categorize complaints and suggest priority levels.
- 🔍 **Duplicate Detection** — Identify potentially related complaints.
- 🏢 **Department Assignment** — Route complaints to the appropriate department.
- ⏰ **Deadline Monitoring** — Track pending and overdue complaints.
- 🚨 **Automated Escalation** — Escalate overdue cases and reopen complaints when closure evidence is insufficient.
- 📊 **Admin Dashboard** — Monitor complaint statuses and service performance.
- 📋 **Activity Logs** — Record automated actions and their reasons.

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

### 🌍 Sustainable Development Goal
**SDG 11 — Sustainable Cities and Communities**

CivicFix AI aims to improve civic accountability, streamline complaint resolution, and support more responsive urban services.

### 🎯 Project Objective
To demonstrate how an agentic system can move beyond simply recording complaints by evaluating changing conditions, executing appropriate actions, and tracking cases through verified resolution.

*Note: AI automation, integrations, and database features depend on the implemented project functionality.*
